- **`Website.googleAnalyticsMeasurementId`, `WebsiteAnalyticsEvent`/`getWebsiteAnalyticsSummaryForRequester` (Phase 7)**: the "guided Google Search Console connection" outcome is almost certainly the same shape as the guided Google Analytics connection Phase 7 just built (store a value the client/agency already has — a verified GSC property — never provision one), and technical audits/performance checks may want to write into the same `WebsiteAnalyticsEvent`-adjacent reporting surface, or a new dedicated model — re-derive which fits before assuming either.
- **ADR 0007's client-visibility architecture** applies to every new client-reachable model this phase introduces, exactly as it has 7 times before across Phases 1, 4, 5, 6, 7. ## Phase 8 major gate

**SEO access and recurring work must be unavailable without the proper entitlement while the base website remains fully functional.** This is the roadmap's own exact wording, and it is a negative/isolation gate rather than a positive-capability gate like every prior phase's major gate — the thing to prove is that a client/website *without* the SEO entitlement is completely unaffected (their base website, builder, forms, analytics, hosting — everything from Phases 1–7 — keeps working exactly as before) while every SEO-specific route/action correctly refuses to operate without the entitlement, server-side, not just hidden in the UI (CLAUDE.md rule 4).

## Phase 8 non-goals (do not start these)

Actually registering with or authenticating against a real Google Search Console account (a guided *connection* to a property the agency/client already owns is in scope, per Phase 7's Google Analytics precedent; provisioning one is not). A real AI provider integration beyond an interface/adapter shape with cost-control scaffolding — "optional" in the roadmap's own wording, and this environment has no real AI provider credentials any more than it has real Namecheap/cPanel ones. Any production deployment/DNS/hosting action beyond what Phase 7 already built — Phase 8 is metadata/SEO/reporting, not another hosting phase.
